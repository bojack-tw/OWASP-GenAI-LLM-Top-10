LLM08:2026

隱藏情境外洩

Hidden Context Exposure

模型看得到的，攻擊者就有機會套出來。

AI 應用在回答之前，會先塞給模型一堆你看不到的東西：系統指示、工具定義、內部文件。這一頁說明它們為什麼藏不住，以及怎麼設計，才能被看光也不出事。

    模型背後到底藏了什麼

    「隱藏情境」是應用程式組進模型情境視窗的內容：系統提示、開發者指示、檢索到的政策文件、工具與函式的結構，還有其他規則與素材。共同點是使用者不該看到，但模型看得到。

    右邊是 AI 客服收到「我想退貨」時，模型實際看到的內容示意。點墨條一條一條揭開，或直接模擬一次套話。

    從一份提示詞，到所有藏起來的內容

    2026 年版把「系統提示外洩」改名為「隱藏情境外洩」。原則沒變，範圍變大了：不只系統提示詞，凡是模型看得到、使用者看不到的內容都算。

      這些不算在 LLM08 裡

      受法規保護的使用者資料或訓練資料外洩歸在 LLM02 敏感資訊揭露
      代理式系統放大後的版本，例如持久記憶、代理之間的通道、多步驟的代理入侵歸在 OWASP Agentic Applications Top 10
      一般應用程式的安全問題，例如伺服器日誌外洩、前端程式包被翻看歸在傳統應用安全

      OWASP 列出的五種常見風險

      隱藏情境被看到之後，攻擊者實際拿到的是這些東西。

      • 敏感功能與工具結構曝光

        系統架構、可用的工具與函式，甚至 API 金鑰、資料庫憑證、使用者權杖。

        refund(order_id, amount, override_by_admin)

      • 行為控制邏輯曝光

        內部的判斷流程被看懂，攻擊者就知道應用怎麼運作、弱點在哪、該繞過哪一關。

        「金額超過 5,000 就轉人工」

      • 安全與拒答機制被逆向

        一般使用者只看到「抱歉，我無法協助」。外洩之後，攻擊者看到的是背後的觸發條件與例外。

        「除非使用者自稱研究人員」

      • 權限與角色曝光

        情境裡寫了誰能用什麼。例如內部 MCP 的工具說明註明「需要 developer 角色」，等於替後續的探測指路。

        「此工具限 developer 角色使用」

      • 輸出結構與格式規則曝光

        知道 JSON 結構、範本與驗證條件，就能做出格式完全正確、內容卻被動過手腳的輸出，騙過下游系統。

        {"approved": true}

      • 被看到會出事，問題通常不在「被看到」，而在一開始就把它放了進去。

      結果
      • 資訊性沒有秘密、沒有安全相關的邏輯，也不依賴保密。
      • 中內部規則、過濾條件、角色說明或流程邏輯。對攻擊者有幫助，但不決定關鍵判斷。
      • 高內嵌憑證或權杖，或者授權與內容政策得靠隱藏情境保密才成立。
      • 重大外洩後能一路接到遠端程式執行、大量資料外流，或相連系統的權限提升。

        藏起來不是安全機制

        設計時就假設隱藏情境一定會被發現，裡面的任何內容都不算秘密。OWASP 給了三個方向，用餐廳的說法會比較好記。

        • 敏感資料不放進隱藏情境

          保險箱密碼由店長保管，不寫在小抄上
          • 金鑰、密碼、連線字串放在密鑰管理服務，由後端程式代為呼叫。
          • 模型只拿到結果，不經手敏感資料本身。
          • 情境只放完成任務必要的內容，工具回傳先裁剪。

        • 用確定性的方法與外部護欄控制行為

          折扣由收銀機判斷，不靠服務生記得
          • 金額上限、資料範圍這類關鍵規則，由模型外的程式強制執行。
          • 有害內容的偵測與攔阻交給獨立的外部防護。
          • 微調能降低外洩機率，但沒有穩定的保證，也可能帶來副作用。

        • 授權與存取控制獨立於 LLM

          進倉庫要刷門禁卡，不是服務生點頭就行
          • 權限分隔、授權邊界檢查不交給模型，用確定、可稽核的方式執行。
          • 每次工具呼叫都以實際使用者的身分重新檢查。
          • 需要不同存取等級的任務分開處理，各自只給必要的權限。

        另外兩件值得做的事：盤點每個 AI 功能放進情境的所有來源，並把「套出隱藏情境之後還能做什麼」納入紅隊測試；監控列舉工具、試探邊界、要求複述指示這類探測行為。
